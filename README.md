A lightweight yet powerful Python port scanning tool for network diagnostics and security awareness. Built with `socket` for reliable TCP port detection.

![Port Scanner Terminal Demo](/Port%20Scanner/asset/image.png)

## 🚀 Features

- **Fast scanning** of 20+ common ports (SSH, HTTP, MySQL, etc.)
- **Service identification** - Shows which services run on open ports
- **Clean interface** - Color-coded results (green=open, red=closed)
- **No dependencies** - Pure Python with built-in libraries
- **Educational** - Great for learning networking fundamentals
